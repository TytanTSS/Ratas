# contentgen

Генератор части контента: пять новых классов (Следопыт, Паладин, Монах, Скальд, Зельевар),
секретные подклассы с учителями и скрытые навыки всех классов. Русский и английский текст
задаются парами в одном месте, поэтому перевод не расходится с контентом.

```bash
python3 tools/contentgen/run.py
```

Нужен Python 3.11 или новее (модуль `tomllib`).

Генератор пишет не целые файлы, а области между метками

```toml
# >>> contentgen: hidden
...
# <<< contentgen: hidden
```

Всё вне областей написано вручную и не трогается. Области:

| Файл в `data/content/` | Область | Что в ней |
| --- | --- | --- |
| `classes.toml` | `classes_new` | определения пяти новых классов |
| `skills/<класс>.toml` | `class` | подклассы, ветки, навыки, умения и призываемые существа нового класса |
| `skills/<класс>.toml` | `secret_path` | секретные подклассы класса (`secrets_data.py`) |
| `skills/<класс>.toml` | `hidden` | десять скрытых навыков класса (`hidden_data.py`) |
| `masters.toml` | `secret_paths` | учителя секретных подклассов и реликвии их заданий |

Переводы новых текстов попадают в те же области одноимённых каталогов `data/i18n/en/`.
Если русский текст уже переведён вне областей, используется существующий перевод.
Править области вручную можно, но при следующем запуске правки пропадут — меняйте данные
в `*_data.py`. Если области в файле нет, генератор допишет её в конец (а файла — создаст).
