# contentgen

Генератор части контента: пять новых классов (`classes_new.toml`), секретные подклассы
с учителями (`secret_paths.toml`) и скрытые навыки (`hidden_skills.toml`). Русский и
английский текст задаются парами в одном месте, поэтому перевод не расходится с контентом.

```bash
python3 tools/contentgen/run.py
```

Скрипт перезаписывает три файла в `data/content/` и одноимённые каталоги в
`data/i18n/en/`. Если русский текст уже переведён в другом каталоге, используется
существующий перевод. Править сгенерированные TOML вручную можно, но при следующем
запуске правки пропадут — меняйте данные в `*_data.py`.
